# ⚡ CYBER SKY - Hashcat Automation Tool

**CYBER SKY** is a powerful, interactive Python automation wrapper designed to streamline PBKDF2-HMAC-SHA1 handshake cracking (`.hc22000` files) using **Hashcat**. It features an interactive character set selection menu, dynamic password length incrementing, and a clean terminal interface.

---

## 🚀 Features

* **Interactive Menu:** Easily choose between Numbers, Alphabets, Alphanumeric, or Full Symbols (Mix) character sets.
* **Dynamic Mask Generation:** Automatically builds optimized Hashcat masks based on user-defined minimum and maximum lengths.
* **Hardware Acceleration:** Integrates Hashcat's high-performance GPU capabilities with built-in `--force` flag support.
* **Cross-Platform Ready:** Works seamlessly on Windows and Kali Linux environments.

---

## 🛠️ Prerequisites

Before running the tool, ensure you have the following installed:
1. **Python 3.x**
2. **Hashcat** (Make sure Hashcat is installed and added to your system PATH, or update the `HASHCAT_PATH` variable in the script).
